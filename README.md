# Engage Business Website

A simple HTML, CSS, and vanilla JavaScript business website.

## Files

- `index.html` — page structure and content
- `main.css` — styling and responsive layout
- `script.js` — mobile navigation, scroll reveal, back-to-top button, and footer year

## Run the project

1. Keep all three files in the same folder.
2. Open `index.html` in your browser.
3. For a better development workflow, open the folder in VS Code and use the Live Server extension.

No npm install or framework is required.

## Images

The replacement business photos are loaded from Unsplash image URLs. This means an internet connection is needed to display them. If you later want the project to work without internet access, download the photos into an `assets` folder and replace the image URLs in `index.html` and `main.css`.

## Before publishing

Update the sample business details in the footer:
- Company description
- Address
- Phone number
- Email address
- Opening hours

The page currently uses the sample name "Engage".
